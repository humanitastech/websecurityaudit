# CMS, plugins, and themes

Identify exact CMS and extension versions, supported APIs, update ownership, roles, and privileged hooks. Inspect custom code before assuming a vendor advisory applies. Select checks for extension permissions, administrative actions, uploads, template escaping, and unauthorized public endpoints.

Use official documentation for the actual version, including WordPress capabilities and Laravel policies where applicable. A CSRF nonce does not establish authorization. Record vulnerable version ranges and reachability separately from abandoned-component risk. Never update or disable production plugins solely as an audit action.
