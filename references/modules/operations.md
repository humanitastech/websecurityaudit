# Hosting and operations

Review public build output, environment separation, preview sites, proxy/CDN rules, cache boundaries, CI/deployment credentials, backup access, key handling, logs, recovery, and incident response within scope.

Separate repository configuration from evidence of the deployed state. Select checks for exposed config/backups, least privilege, alerting, sanitized logs, restoration evidence, and availability protections. Never run load/DoS or live restoration tests without explicit authorization. Record provider-owned controls and unavailable operational evidence rather than assuming a website scan can verify them.
