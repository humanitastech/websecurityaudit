# Dependencies and build supply chain

Inspect manifests, resolved lockfile versions, build hooks, registry provenance, and CI permissions. Match advisories to actual direct/transitive versions, then assess whether vulnerable behavior is used. Do not replace missing installed versions with latest upstream releases.

Distinguish known vulnerability, maintenance concern, and unknown registry data. Record unsupported formats, vendored/private packages, and transitive coverage limits. Never install or execute packages just to inventory them. Missing data is neither proof of compromise nor a clean result.
